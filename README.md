# marketing-channel-ab-testing
A digital marketing company aims to improve customer engagement by evaluating the effectiveness of different marketing channels and campaign variants. Leadership requires statistically validated recommendations to optimize marketing investments and improve user retention.

# Key Business Questions
Does marketing Variant B significantly improve user engagement compared to Variant A?
Which marketing channels drive the highest user interaction?
Are differences in clicks and time spent statistically significant?
Which customer segments respond best to different campaign strategies?
What actionable recommendations should stakeholders implement?
